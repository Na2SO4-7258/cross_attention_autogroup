# dyNAmic Transfer Touch

数据的最小单位是（原图，专家图）对。FiveK 每张原图和五张专家图组成五个图对，专家编号不作为输入。

## 分组阶段

将（原图 RGB，专家图 RGB，专家图−原图 RGB）九通道输入差异编码网络 `model.b`，逐通道全局平均池化，得到 `edit_dim` 维变化信息向量。按照欧氏距离选取最近的 `num_reference` 个图对，排除与当前原图同源的所有图对。分组与参考特征提取复用同一个差异编码网络。

分组检索仍使用当前专家图构造变化向量，因此完整评估流程仍需要答案图；下面的注意力选择与生成不使用当前专家图。

## 每个区域独立选择参考图

当前原图只经过一次已有的信息编码网络 `model.a`，输出作为 Q 的输入。各参考图的（参考原图，参考专家图，参考专家图−参考原图）经过共享差异编码网络 `model.b`，输出作为 K、V 的输入。参考选择与修改迁移复用同一次交叉注意力，删除了使用当前图九通道差异特征的额外打分步骤。

两侧特征插值为 `[edit_dim, S, S]`，其中 `S=attention_spatial_size`，默认 64。64×64 指空间特征网格，共 4096 个区域，并非每个区域包含 64×64 个原图像素。

对当前区域 i、参考图 r、参考区域 j、注意力头 h：

```text
L[b,h,r,i,j] = abs(Q[b,h,i] · K[b,h,r,j] / sqrt(head_dim))
score[b,r,i] = max_j mean_h L[b,h,r,i,j]
selected[b,i] = argmax_r score[b,r,i]
```

在 softmax 前用最大绝对 QK 选择参考图。多头先对绝对值取平均，让同一当前区域的所有头使用同一张参考图；相同分数优先选择列表中靠前的图。不同当前区域可以选择不同参考图，也无需与参考区域坐标一致。

选定参考图后，各头只在该图内部沿参考区域维对 L 做 softmax，再加权求和 V，合并注意力头并经过输出投影和 `context_edit` 得到修改信息。绝对值较大的负 QK 也代表强匹配。图内保留区域加权汇总，并非仅复制 argmax 区域的单个 V。

默认路径不再对多张参考图进行加权平均，也不做跨参考图 softmax。返回的 `scores`、`weights` 均为 `[B, R, S*S]`；weights 是每个位置的 one-hot 参考选择掩码。硬 argmax 本身不可导，被选中的图内注意力与编码特征仍通过生成损失训练。`current_expert`、`temperature` 保留调用兼容性，不参与此步骤；原有温度调度对硬选择无效。

## 生成与可视化

编辑特征恢复为 `[B, edit_dim, S, S]`，输入小型 U-Net，插值到原图分辨率，预测 RGB 残差并叠加到原图。当前专家图用于计算训练损失。

可视化仅显示参考图实际被选中位置的注意力，`selected share` 表示该参考图被选中的位置比例，不是整图融合权重。

## 消融与兼容性

- `ablation_random_reference`：随机候选替代分组近邻检索。
- `ablation_uniform_weight`：显式关闭硬选择，以各参考图等权平均作为对照。
- `ablation_cnn_fusion`：保留逐位置参考选择，以原图与参考九通道拼接后的 CNN 特征替代注意力迁移值。

旧权重参数结构兼容，但注意力语义已经改变，需要重新训练评估。旧 checkpoint 配置可能恢复旧空间尺寸。64×64 网格的单张注意力矩阵是 32×32 的 16 倍，可调整配置中的尺寸和 batch size。
