# dyNAmic Transfer Touch

## 分组检索

数据单位是（原图，专家图）对。九通道（原图、专家图、专家图减原图）经共享编码器 model.b 和全局平均池化得到检索向量，按欧氏距离选择参考，排除同源原图。检索仍需要当前专家图；注意力和生成不使用当前专家图。

训练 epoch 随机排列图对，在 config.py 中用 batches_per_chunk 设置每个 chunk 包含几个 batch，默认 25。每块最多包含 batches_per_chunk × batch_size 个图对（默认 25 × 4 = 100），最后一块允许不足。每块开始前用最新模型重新编码完整训练候选池，只为当前块检索参考，再训练该块。候选池不限于 chunk。验证与测试维持原流程，测试参考来自训练集。

chunk 大小仅在 config.py 中设置，不新增命令行输入。训练显示每个 chunk 内的 batch 进度，进度条标明当前 chunk 编号和总数，不额外显示候选编码进度或分组详情。检索文件按 epoch 和 chunk 保存；矩阵行顺序对应同名 top-reference JSON 键顺序。每块重算候选编码会增加检索开销。

## 注意力与生成

原图经 model.a 得到完整编码，参考九通道经 model.b 得到完整参考编码。仅 Q/K 分支插值到 attention_spatial_size=32 的网格，V 直接使用插值前的完整参考编码，移除 V 投影、输出投影和 context_edit。

```text
L[b,h,r,i,j] = abs(Q[b,h,i] · K[b,h,r,j] / sqrt(head_dim))
score[b,r,i] = max_j mean_h L[b,h,r,i,j]
selected[b,i] = argmax_r score[b,r,i]
A = mean_h softmax_j(L)
```

每个区域独立选择参考，分数相同时选择靠前的参考。将 A 的参考区域轴双线性插值到原参考编码网格并重新归一化，再与 V 相乘，随后恢复当前区域轴到当前原图编码网格。线性插值允许分步计算，等价于先恢复矩阵两侧空间轴再乘 V，避免存储完整大矩阵。参考选择掩码用最近邻恢复。

注意力迁移特征直接送入生成 CNN，不再加上当前原图编码。256×256 输入对应 64×64 编码，32×32 仅用于注意力打分。生成器接收原图 RGB 和迁移特征，经过 CNN、全局平均池化和线性层，为每张图预测 RGB 三个增益 a 和三个偏移 b，共六个整图共享参数。最终输出为 clamp(a × 原图 + b, 0, 1)，不再预测逐像素差值，也没有原先 ±0.25 的差值限制。参数初始化接近恒等映射，原有输出与原图距离正则项保留。这是逐通道全局仿射映射，不包含跨通道混合或非线性色调曲线。

scores、weights 返回 [B,R,S*S]。硬选择不可导，图内注意力和编码器仍通过生成损失训练。current_expert、temperature 保留调用兼容性，不参与注意力和生成。可视化显示打分网格的注意力，selected share 表示参考被选中的区域比例。

## 消融与兼容性

可视化首行依次为原图、输出、答案；之后每个参考独占一行，依次为当前原图、参考原图、参考专家图。相同颜色和编号表示对应的注意力区域，参考原图与专家图共享区域标注。

最后两行分别展示输出相对原图、答案图相对原图的逐像素亮度、饱和度和冷暖变化。亮度使用 RGB 加权亮度（0.2126R + 0.7152G + 0.0722B），饱和度使用 HSV S，冷暖使用 (R-B)/(R+G+B) 的变化作为代理量，不是真实 Kelvin 色温。红色表示增加（冷暖图为变暖），蓝色表示减少（变冷），白色表示零变化。同一指标的上下两张热力图共用对称色标，以两者最大绝对变化量确定范围，具体范围标在图下。

- ablation_random_reference：随机参考替代近邻检索。
- ablation_uniform_weight：各参考等权平均。
- ablation_cnn_fusion：用完整编码分辨率的 CNN 融合特征替代注意力迁移值。

新结构不兼容旧 checkpoint，需要重新训练。自动加载会跳过旧残差模型；显式 --resume 和 test.py 需要新结构 checkpoint。
